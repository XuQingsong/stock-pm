# stock-pm 产品需求

版本：1.2  
日期：2026-09-08  
口径：只写你描述过的目标。不写当前页面、接口、数据源或计算公式。评审成品时用本文对照，而不是用成品反推本文。

富途截图不在本仓库。文中「对照富途」只保留你指出的内容类别，不含后来做进代码的算法与供应商。

## 1. 要做成什么

给自己用的美股自选研究工具。

每天围绕三件事：

1. **看清这家公司现在处在什么环境里**：基本面还值不值这个价；当前宏观 / 行业 / 公司消息是正面还是负面；公司或行业近期情绪是恐慌、冷淡还是过热。
2. **看清前一天盘面到底发生了什么**：不是看一根 K 线，而是量价、筹码位置、破位后的走法，并和上面的基本面、消息面、情绪面连起来，判断是诱多/诱空、真转势，还是吸筹/逃跑。
3. **复盘并迭代判断**：用白话总结昨天；解释为什么这样走；开盘前给出可验证的预测（当天或一段时间）；用之后的价格印证；判断失效或消息反转时醒目提示；用结果改方法。

没时间盯盘，隔日能看完即可。不是交易执行工具：不下单、不管仓位、不算账户盈亏。

信息必须经过处理后再给结论。堆一堆新闻标题、指标和 K 线、不加判断，不算满足需求。

## 2. 基本面、消息面、情绪面

打开一只自选，这三层要能合成「现在该怎么理解这只票」，而不是三个互不相干的列表。

### 2.1 基本面：这家公司还值不值这个价

要能直接看出：

- 这只票**过去一年涨了多少**（要有摘要，不能只有一串日 K）。
- **财报有没有持续达标**：近一年各季实际对预期；一年下来有没有持续超预期；营收有没有减速。
- **行业是否还在高速发展**，是不是还在成长期。
- **现价贵不贵**：股价是否还符合估值。

名称、交易所、板块等基本信息要有，但它们只是前提，不是这条需求的答案。

### 2.2 消息面：当前对这只票是正面还是负面

消息面要分层，并且落到「对这只票 / 这个行业意味着什么、偏多还是偏空」，不要把原始资讯铺开。

**宏观**

- 各国央行政策，当前尤其是美联储加息 / 降息预期。
- 债市与汇率压力，例如日本汇率、美国长端利率。
- 国际热门事件，例如美伊局势、油价高企。

要能看出：这件事现在是在给高估值板块加压，还是在给降息交易松绑，而不是只罗列「非农、CPI、FOMC」日历。

**行业**

- 该标的所在行业正在发生什么，以及这对股价是正面还是负面。
- 例如 MU：存储周期、行业缺货。
- 例如 AAPL：某日发布会临近，当前消息面偏正面还是负面。

**公司**

- 最近足以引起股价大幅波动的公司新闻。
- 例如 INTC 与某公司的代工合作。

同一条宏观新闻，对不同自选可以是不同方向；没有映射到自选的噪音不必占地方。

### 2.3 情绪面：公司或行业近期怎么走、现在怕什么

情绪面指**该公司或行业近期的走势和氛围**，不是标题里数正面词。

要能直接说出类似这样的话：

- 7 月存储因为韩国去杠杆持续下跌，情绪很恐慌。
- 美伊冲突突然扩大、油价上涨，高估值板块承压。

情绪面要能和消息面、基本面互相印证：消息是导火索，情绪是最近这段路已经走出的状态。只贴新闻、不说近期怎么走，不算情绪面。

## 3. 盘面分析：前一天到底发生了什么

要回答的是「昨天这笔交易日里，盘面在干什么」，并且必须接到第 2 节的结论上。只画 K 线、把均线高低量罗列出来，不满足本条。

前一天至少要能看出：

- **量价形态**：量大拉升、量小拉升、放量下跌、缩量下跌（同类表述即可，但必须是判断，不是只给成交量数字）。
- **主力价位**：大部分筹码分布在什么位置。
- **压力位、支撑位**。
- **盘中有没有破位**；破位之后怎么走（立刻拉回、继续下杀、还是假突破）。
- 均线位置仍以你指定的 **MA5 / MA20 / MA50 / MA200** 为准。
- 换手、是否突破关键点，要能用来解释走法，而不是单独堆指标。

结合第 2 节之后，盘面分析要能给出**相互关联的判断**，例如：

- 大涨时：是主力在诱多，还是趋势真的在转、结构真的变了。
- 大跌时：是主力在吸筹，还是在逃跑。

这些判断可以标明是推断，但不能缺失。没有「和消息/情绪/基本面对上没有」的盘面，只是行情复述。

对照富途时你指出个股上还需要能看到：可切换周期的 K 线与均线、筹码分布、资金流向、财务估值、资讯、期权。那些是看盘的材料，用来支撑本节和第 2 节，不能代替本节的结论。图上均线不能用券商默认短均线顶替 MA5 / 20 / 50 / 200。

## 4. 复盘迭代：总结、解释、预测、跟踪、改判断

本条一定要有**预测**和**迭代**。没有预测、没有用结果回头改判断，就不算复盘模块。

### 4.1 先总结昨天

用简洁、好懂的话描述昨天盘面，内容来自第 3 节的结论，不是再贴一遍指标表。

### 4.2 再解释为什么这样走

用情绪面、消息面、板块、K 线、主力筹码分布、换手率、是否突破关键点等，解释**这一根已经走完的盘面为什么是这个样子**。

解释要像在讲一条因果链，而不是关键词拼接。质量应达到这种程度（例子只说明「讲清楚」的标准，不是功能清单）：

> 北京时间上周五晚 8 点半，非农超预期、加息预期大幅升温，但存储和半导体逆势上涨。可能的原因是：市场不相信这份非农、交易员大多押注 9 月不降息；半导体近期跌多、财报普遍较好，更像板块轮动里的补涨。

没有消息/情绪依据时，必须明说「解释不了」，不能硬编。

### 4.3 开盘前给出预测

在开盘前（例如美东时间早上 7 点前）给出对接下来盘面的判断。

- 能预测当天，就预测当天。
- 某一天看不清，也可以预测**一段时间**（几天到几周），但必须把预测写清楚，方便后面印证。
- **尽量量化**。说得出的话，应包含：时间窗口、上涨大概到哪、最多能跌多少。说不出精确数字时，也要有可判定对错的边界，不能只写「偏多/观望」。

例如：因某公开持仓大幅增加，判断 INTC 未来两周内补涨约 10%，期间最多下跌不超过 5%。这是一条合格预测；「短期看好」不是。

### 4.4 用之后的价格不断印证

预测生效期间，要持续拿到该标的价格来对照这条判断。

任意一个约定边界被打破，就判定这次判断出错，并记下原因。边界包括但不限于：

- 时间到了却没走出预期；
- 上涨幅度已经超出当时的预测框架；
- 下跌幅度超过当时给出的下限（如上例跌破 5%）。

预测尚未失效时，也要能看到「现在走到哪了、还在不在框里」。

### 4.5 判断变更必须醒目

在跟踪期间，若突发事件、消息面或情绪面反转，使你对原判断作出修改：

- 必须及时给出通知；
- 变更要非常醒目，不能埋在普通复盘文字里被当成日常更新。

原判断、新判断、变更原因都要留痕，方便事后看自己为什么改口。

### 4.6 用结果迭代方法

要能回看一段时间里：哪些预测对了、哪些错了、错在哪一类（消息判断、情绪、破位、时间窗口、幅度）。用这些结果强化或修正以后的判断方式。旧记录不能每天覆盖掉。

## 5. 用法上还要满足的

- 早上（开盘前）能扫**整份自选**：环境（基本面/消息/情绪）、昨天盘面结论、当前有效预测及是否已被打脸或改口。
- 对某一只，这三层要能放在一起看，而不是各看各的。
- 自选是自己的名单，要能自己增删，不能写死在程序里。
- 某天没盯盘时，事后要能回看那天盘面怎么走的。
- 缺数据就标明缺；不能为了看起来完整去编行业增速、新闻影响、主力意图、估值结论或预测。

## 6. 明确不做

- 交易执行：下单、持仓同步、账户、风控。
- 盘中替代券商去盯盘：不要求人坐在实时盘口前；但盘面结论仍要能回答第 3 节，不能用「没有实时盘口」当理由只画日 K。
- 把原始资讯或指标堆出来当产品：未处理的新闻流、未解释的筹码图、未量化的「偏多」都不够。
- 没有依据却宣称：行业成长期、便宜/贵、诱多/吸筹、次日或未来两周必涨。

## 7. 怎样算满足（用来评审成品）

评审时只问「能不能回答」，不问「有没有某个菜单或某个供应商」。

### 基本面 / 消息面 / 情绪面

打开一只自选，应能不靠记忆回答：

1. 过去一年大概涨跌多少？财报是否持续超预期？营收有没有减速？
2. 行业还在不在高增长？现价贵不贵？依据和缺口是什么？
3. 当前宏观（央行、债市汇率、国际事件）对它是利多还是利空？
4. 行业正在发生什么、偏正面还是负面？（如存储缺货、发布会临近）
5. 公司最近有没有足以拉动股价的新闻？
6. 公司或行业近期走势的情绪是什么（恐慌、承压、补涨、过热）？

若只是新闻列表 + 几个财务数字，没有「对这只票是正面还是负面」的处理结论，则本条不满足。

### 盘面分析

看完前一天，应能回答：

1. 昨天是放量涨、缩量涨、放量跌还是缩量跌？
2. 大部分筹码在什么价位？支撑、压力在哪？
3. 盘中破没破位？破了之后怎么走？
4. 结合基本面、消息面、情绪面：大涨更像诱多还是转势？大跌更像吸筹还是逃跑？

若只有 K 线和基础字段，没有量价判断，或盘面与消息/情绪对不上号，则本条不满足。

### 复盘迭代

应能走完一轮并在之后仍找得到：

1. 用白话总结昨天盘面。
2. 用消息、情绪、板块、K 线、筹码、换手、关键点解释为什么这样走（讲得清因果，或明说解释不了）。
3. 开盘前（如美东 7 点前）有一条可验证预测：当天或一段时间，尽量含时间、上涨、下跌边界。
4. 预测期内持续对照价格；任一边界被打破即判错并记录原因。
5. 突发事件导致改判断时，有醒目提示，且新旧判断都留痕。
6. 一段时间后能回看对错并用来改方法；旧记录还在。

若只有收盘摘要、没有量化预测、不能跟踪打脸、改口不明显，则本条不满足。

实现里用什么库、什么行情源、几个页面、指标怎么算，都不属于需求。那些是实现选择；满足与否只看本节的问题能不能被成品答上。
