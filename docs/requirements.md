# stock-pm 产品需求

版本：1.1  
日期：2026-09-08  
口径：只写你描述过的目标。不写当前页面、接口、数据源或计算公式。评审成品时用本文对照，而不是用成品反推本文。

富途截图不在本仓库。第 4 节只保留你当时用富途指出的**内容类别**，不含后来做进代码的算法与供应商。

---

## 1. 要做成什么

给自己用的美股自选研究工具。

每天两件事：

1. **第二天早上用几分钟看自选**：这家公司基本面是否还值这个价，昨天盘面是否健康。
2. **收盘后复盘并迭代**：用情绪、消息、板块解释当天为什么这样走，写下明天大致判断，再用第二天实际走势打分、改方法。

没时间盯盘，所以隔日能看完即可，不要求盘中实时。

不是交易执行工具：不下单、不管仓位、不算账户盈亏。

## 2. 三条核心需求

### 2.1 基本面：这家公司还值不值这个价

要能直接看出：

- 这只票**过去一年涨了多少**（要有摘要，不能只有一串日 K）。
- **财报有没有持续达标**：近一年各季实际对预期；一年下来有没有持续超预期；营收有没有减速。
- **行业是否还在高速发展**，是不是还在成长期。
- **现价贵不贵**：股价是否还符合估值。

名称、交易所、板块等基本信息要有，但它们只是前提，不是这条需求的答案。

### 2.2 隔日盘面：昨天是否健康

第二天几分钟看完即可。要能直接看出：

- **量是否放大**
- **支撑 / 压力**守没守住，有没有破位
- **情绪面**（当天消息驱动的盘面情绪，不是标题里数正面词）
- **近一周趋势**向上还是向下
- **均线位置**：MA5 / MA20 / MA50 / MA200（这是你要看的位置，不是券商软件默认的那套短均线）
- **股价是否健康**、中长期结构如何：最后要能合成一句人能用的判断（例如趋势还好、已经过热、还是在走坏），而不是一堆互不相干的指标

### 2.3 复盘迭代：解释 → 预判 → 对照 → 改方法

要形成习惯，而不是每天覆盖一段量价复述：

1. 收盘后能把当天盘面看完。
2. 用情绪、消息、板块解释**今天为什么这样走**。
3. 留下对**明天大致走势**的判断。
4. 第二天把实际涨跌、量、是否破位拿来对照「昨天怎么看」。
5. 能回看一段时间的对错，用来改方法。旧判断要留着，不能每天冲掉。

## 3. 用法上还要满足的

- 早上能扫**整份自选**，不必一只一只点进去才知道昨天健不健康。
- 对某一只，要能把基本面、盘面、复盘放在一起看。
- 自选是自己的名单，要能自己增删，不能写死在程序里。
- 某天没盯盘时，事后要能回看那天盘面怎么走的。
- 缺数据就标明缺；不能为了看起来完整去编行业增速、新闻影响、估值结论或次日预测。

## 4. 对照富途后补充的内容（不是第三条需求）

你后来用富途个股页说明：回答上面三个问题的时候，个股上还需要能看到券商软件里那些研究模块，而不是只有几行摘要。

需要能看到的内容类别：

| 你指出要有的 | 用来支撑哪条需求 |
| --- | --- |
| 可切换周期的 K 线、均线、量 | 隔日盘面：位置、量、趋势 |
| 财务 / 财报细节 | 基本面：有没有达标 |
| 估值 | 基本面：现价贵不贵 |
| 筹码分布一类的位置信息 | 隔日盘面：支撑压力、是否健康 |
| 资金流向一类的买卖力量 | 隔日盘面：量与情绪 |
| 资讯 | 盘面情绪，以及复盘「为什么这样走」 |
| 期权相关结构 | 盘面情绪与位置的补充 |

说明：

- 富途用来**指定要看哪些内容**，不是要求做成富途，也不要求盘中盯盘、真实盘口、官方筹码或「主力/散户」身份。
- 图上均线仍以你指定的 **MA5 / MA20 / MA50 / MA200** 为准。富途默认另一套短均线的话，不能拿那套顶替你要看的位置。
- 复盘迭代（写下判断、次日对照、按周回顾）是你自己的习惯，富途没有对应模块，不能用 K 线或资金页代替。

## 5. 明确不做

- 交易执行：下单、持仓同步、账户、风控。
- 盘中替代券商：实时盘口、逐笔全市场、Level 2。
- 把无法得到的数据做成假完整：没有行业数据却宣称行业成长期；没有可靠估值却下「便宜/贵」结论；没有消息依据却解释涨跌原因。

## 6. 怎样算满足（用来评审成品）

评审时只问「能不能回答」，不问「有没有某个菜单或某个供应商」。

### 基本面

打开一只自选，应能在不靠记忆的情况下回答：

1. 过去一年大概涨跌多少？
2. 近一年财报是不是持续超预期？营收有没有减速？
3. 它所在行业是不是还在高速发展？
4. 以现价看，贵不贵？依据是什么？缺什么依据？

若只能看到散落的 PE、单季 EPS、主题标签，而不能形成上面四句结论，则本条不满足。

### 隔日盘面

第二天早上扫自选，应能在几分钟内对每只回答：

1. 昨天量放没放？
2. 支撑/压力守没守住？
3. 近一周往哪走？
4. 相对 MA5 / 20 / 50 / 200 在什么位置？
5. 盘面算健康、过热还是走坏？
6. 当天消息/板块情绪是否帮得上忙？

若这些数字算过但早上扫不到、或均线和图上不是你要的那四条、或情绪仍是标题打分，则本条不满足。

### 复盘迭代

收盘后应能完成一轮，第二天仍找得到：

1. 看到当天盘面。
2. 看到用消息/板块做的原因解释（并知道这是推断）。
3. 写下明天大致判断。
4. 次日看到「昨天看法 vs 今天实际」。
5. 过一周仍能回看对错，旧记录还在。

若只有量价复述、没有原因、不能留判断、或每天覆盖旧摘要，则本条不满足。

### 富途指出的内容

个股上应能看到第 4 节那些内容类别，并用来服务三条问题。只有模块、却回答不了第 2 节的问题，仍算不满足。

---

实现里用什么库、什么行情源、几个页面、指标怎么算，都不属于需求。那些是实现选择；满足与否只看本节的问题能不能被成品答上。
