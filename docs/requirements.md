# stock-pm 产品需求

版本：1.0  
日期：2026-09-08  
来源：原始三条研究问题 + 富途个股界面对照后的模块补充。本文是当前完整需求，不是实现进度表。

## 1. 产品定位

面向个人价值投资的美股自选研究工具。

日常用法只有两段：

1. **第二天早上用几分钟看自选**：这家公司基本面是否还值这个价，昨天盘面是否健康。
2. **收盘后复盘并迭代判断**：用情绪、消息、板块解释当天为什么这样走，写下明天大致看法，再用次日走势对照、改方法。

这不是交易执行系统，也不替代券商 App 的盘中盯盘。仓位、下单、账户、风控不在范围内。

对照富途的目的是借用个股页「看什么、怎么排」，不是复制实时盘口、主力资金或官方筹码。富途有而数据源做不到的内容，必须空着或标明代理口径，禁止编造。

## 2. 用户与约束

- 使用者：一个人，自选大约数只到十几只美股与 ETF（当前种子含 `MU, INTC, AAPL, GOOGL, NVDA, SKHY, NOK, AVGO, QQQ`）。
- 没时间盯盘；隔日看延迟行情即可。
- 主数据：Alpaca 延迟行情入库 PostgreSQL，再由 FastAPI / 静态页查询。
- 缺数时显示「数据源暂未提供」或等价说明，不填估算值冒充真实值。
- 规则、模型和用户判断必须分开标注，都不能写成投资建议。

## 3. 三条核心问题（不变）

所有页面都为回答这三个问题服务。富途界面只补充模块与展示，不替换这三条。

### 3.1 基本面：这家公司还值不值这个价

要能直接回答：

| 问题 | 最低交付 |
| --- | --- |
| 过去一年股价 | 一年涨跌幅摘要，不只是把日 K 摊开 |
| 财报有没有持续达标 | 近一年季度实际 vs 预期；「过去四季超预期次数」；营收是否减速 |
| 行业是否还在高增长 | 先回答本公司同比与增长阶段；行业成长期只用同主题自选对比，不编 TAM / 官方行业增速 |
| 现价贵不贵 | 现价相对自身一年估值分位；Forward PE、分析师目标价未提供时，不得给出「便宜/贵」结论 |

基本信息（名称、交易所、板块、主题标签）是前置条件，不是研究结论。

### 3.2 隔日盘面：昨天是否健康

第二天用几分钟看完，不要求盘中实时：

| 问题 | 最低交付 |
| --- | --- |
| 量是否放大 | 相对 20 日量比，放量/缩量可扫 |
| 有没有破位 | 是否守住或跌破最近支撑/压力；20 日高低点突破需收盘确认 |
| 近一周趋势 | 近 5 日涨跌方向，总览必须展示 |
| 均线位置 | **MA5 / MA20 / MA50 / MA200**（日线研究口径）。图上均线必须与该口径一致，不用富途默认的 MA5/10/20/30 替代 |
| 盘面是否健康 | 把均线结构 + 量 + 位置合成一句：趋势健康 / 过热 / 走坏 / 缩量无方向 / 观察 |
| 情绪面 | 当天消息与板块影响，不是标题关键词正负分 |

### 3.3 复盘迭代：解释昨天 → 写下明天 → 用次日打分

要形成习惯，而不是每天覆盖一段量价复述：

1. 收盘后看完整盘面。
2. 用情绪、消息、板块解释「今天为什么这样走」，并标明推断不是因果。
3. 留下对明天的大致判断（偏向、看法、关注位、原因假设）。
4. 次日自动对照实际涨跌、量、是否破位，形成「昨日看法 vs 今日实际」。
5. 按周回看命中率；旧判断不得被覆盖掉。

## 4. 信息架构

按「看什么」分页，不按数据源分页。

| 页面 | 回答的问题 | 范围 |
| --- | --- | --- |
| `/` 市场总览 | 今天整个自选盘面怎么样 | 全部自选 |
| `/stock/{symbol}` 个股分析 | 这只标的现在什么状态 | 单标的 |
| `/replay` 盘面回放 | 某天/某段时间发生了什么 | 单标的，最多两只对比 |
| `/review` 每日复盘 | 收盘后解释、确认明日看法、对照次日 | 全部自选 |
| `/settings` 设置 | 管理自选 | 配置 |

持仓、成交、账户默认不出现在页面上。表结构可保留，待接入新券商再开。

## 5. 市场总览 `/`

早上打开后应能扫完整自选，不必进个股。

必有模块：

1. **隔日盘面简报表**：标的、最新价、日涨跌、量比、5 日方向、MA5/20/50/200 位置与排列、支撑/压力守住或跌破、健康度、昨日判断对照。
2. **宏观事件与板块影响**：近窗口内非农 / CPI / FOMC / PCE 等；规则映射到自选主题（如降息预期升温 → 利多高估值成长）。只覆盖预设事件类型。
3. **最新复盘摘要**：可跳到 `/review` 与对应个股复盘。
4. **今日异动**：大额成交、期权异动。期权异动不能判断主动买卖方向。
5. **近期财报日历**：EPS 实际/预期、财报后 1 日反应。
6. **新闻 → 板块影响**：只展示能映射到自选主题的条目；未命中的单独列出，不编造影响。
7. **Cboe 期权市场概览**（可选市场层）：一家交易所日终统计，不得与个股期权墙横比。

## 6. 个股分析 `/stock/{symbol}`

个股页形态对照富途常见行情页，研究问题仍是第 3 节三条。

### 6.1 顶栏（始终可见）

- 代码、名称、交易所、板块、主题标签。
- 最新价、涨跌额、涨跌幅。
- 报价条至少包含：成交量、量比、总市值、PE TTM、RSI14、距 52 周高、距 52 周低、数据时间、数据源。
- 可切换自选内其他标的。
- 不要求复制富途全部盘口字段（开高低、换手、振幅、成交额等）。研究用字段优先于盘口字段。

### 6.2 标签结构

| 标签 | 主要回答 | 来源 |
| --- | --- | --- |
| 图表 | 价量、均线、周期、支撑压力 | 富途 K 线页 |
| 复盘 | 为何走、明日看法、我的判断与对照 | 原始第 3 条，富途没有 |
| 财报 | 是否达标、一年结论 | 原始第 1 条 + 富途财务页粒度 |
| 估值 | 现价相对自身贵不贵 | 原始第 1 条 + 富途估值页 |
| 筹码与资金 | 位置、大单、资金代理 | 富途筹码/资金，必须降级口径 |
| 资讯与期权 | 消息驱动与期权结构 | 原始情绪面 + 富途资讯/期权 |

### 6.3 图表

- 周期：`1m / 5m / 15m / 60m / 1d / 1w / 1M`。分钟线来自延迟行情重采样，日/周/月来自日线重采样。
- 主图：K 线 + 成交量。
- 均线：**当前周期的 MA5 / MA20 / MA50 / MA200**，可开关。不足窗口则该均线为空。
- 分钟图额外叠加**日线 MA50 / MA200**，避免短周期图上看不见中长期位置。
- 副图：KDJ(9,3,3)，随所选周期变化。
- 叠加：POC、由成交量分布得到的支撑/压力。标注为参考位，不是订单簿。

### 6.4 复盘（个股）

与 `/review` 同一套记录，此处看单标的详情：

- 日终健康度、评分、量价摘要、均线位置、5 日涨跌、支撑/压力、突破状态。
- 可能解释走势的当日新闻与宏观（规则映射，非因果）。
- 模型「为何这样走」与「明日看法」（仅基于已提供事实，禁止编造）。
- 用户确认：偏向（偏多 / 中性 / 偏空 / 观望）、看法、备注。
- 上一判断对照结果。

### 6.5 财报

- 最新一季：营收、净利润、EPS 的实际 vs 预期，以及超预期/低于预期。
- **一年结论**：一年涨跌、距 52 周高、近四季 EPS/营收超预期次数（缺预期的季度不计入）、营收同比、增长阶段（仍高增 / 加速 / 放缓 / 转负 / 样本不足）、同主题自选对比、相对自身估值标签。
- 历史财报后 1 / 5 / 20 日股价反应。价格反应不代表未来表现。
- 净利润预期、Forward PE、分析师目标价若套餐不提供，显示未提供，不用估算填补。

### 6.6 估值

- PE TTM、相对自身一年分位、偏低/中性/偏高（仅在样本足够且口径一致时）。
- PB、PS：有则展示，无则标明未提供、不做推算。
- PE 历史曲线；分位带需足够样本，不得用过短本地快照冒充长期估值。
- 口径写明：例如「用当前 TTM EPS 回推一年 PE」，不是当时实时 PE。
- Forward PE / 目标价缺失时，不做贵贱结论。

### 6.7 筹码与资金

对照富途「筹码分布 / 资金流向」，但必须用可复现的代理，并在页上持续展示免责声明。

| 用户在富途看到的 | 本产品交付 | 禁止声称 |
| --- | --- | --- |
| 筹码分布、获利盘、密集峰 | 把每根日 K 成交量在高低价区间均摊到价位桶；POC、价值区（约 70% 量）、现价下方量占比 | 交易所披露持仓成本、主力筹码 |
| 主力 / 超大单 / 大单 | 单笔金额分层：20–50 万 / 50–100 万 / 100 万+（阈值可配，默认大单门槛 $200,000）；近 5 日净额时间线 | 识别机构或散户 |
| 资金流向 | CMF(20)、OBV 等日 K 代理；大单方向由 tick rule **推断** | 真实主动买卖、Level 2 |

采集采用两步法：先用 1 分钟 K 线定位放量分钟，再只对这些窗口拉逐笔筛大单。分段量价（ZigZag）输出每段涨跌、相对量、VWAP 位置、推断大单净额，供回放页使用。

### 6.8 资讯与期权

- 个股新闻：主题标签；能映射到板块影响的单独列出，映射不上的不强制归类。
- 最近到期期权墙：按行权价展示 Call / Put 未平仓，用于观察墙的位置。
- 公开期权链 / indicative 数据不能判断主动买卖方向。
- 个股墙不得与总览 Cboe 全市场 P/C 当作同一个数字。

## 7. 盘面回放 `/replay`

用于回答「那天盘中到底怎么走的」，服务第 3.2 与 3.3 条，不是实时页。

- 单标的一张回放卡，最多两只并排，独立价格轴。
- 固定美股常规时段（纽约 09:30–16:00）1 分钟 K 线；区间长度有上限。
- 图下展示：当日分段量价、大额成交摘要、当日复盘。
- 休市日明确提示无分钟线 / 无复盘，不把缺数当成异常行情。

## 8. 每日复盘 `/review`

这是第 3.3 条的主界面。

对每个交易日、每只自选：

1. **盘面事实**：评分、量价话术、支撑压力、分段量价入口、健康度。
2. **解释层**：当日该标的新闻、命中主题、宏观对自选主题的方向。明确写「可能解释盘中走势的因素」。
3. **模型层**（可选）：基于上述 JSON 事实生成「为何走」和明日偏向；资料不够必须明说；事实未变则不重复调用。
4. **用户层**：确认偏向、看法、关注位/备注。用户确认优先于模型，模型优先于规则草稿。
5. **对照层**：次日写入实际涨跌、量比、是否破位，与昨日偏向比较为符合 / 相反 / 含糊。
6. **统计层**：已确认记录的命中率，与全部对照命中率分开统计。按周可回看，历史行保留。

美股休市日：提示当日休市、复盘的是上一交易日，不生成假复盘。

## 9. 自选与设置 `/settings`

- 自选存数据库，不写死在代码。字段含 symbol、名称、交易所、asset_class、sector、主题标签、利率敏感度、active。
- 新增：提交代码 → Alpaca 校验并回填名称/交易所 → 后台回填约一年日线、基本面、期权 → 标记 active。
- 停用为软删除，历史 K 线、复盘、大单保留。
- ETF 用 `asset_class` 判断，不硬编码个别代码。
- 大额成交阈值可配。

## 10. 数据源与诚实边界

同一指标页面上只展示一个写入源。相邻模块可以来自不同层，但必须让用户分得清。

| 看到的内容 | 唯一写入源 | 不要拿去比的 |
| --- | --- | --- |
| K 线 / 报价 / 量比 | Alpaca（日线优先 SIP；免费层约 15 分钟延迟） | FMP / Nasdaq 估值用价 |
| PE TTM、利润表、EPS 实际 | 有 key 走 FMP，否则 Nasdaq 回退 | 两套 PE 算法混在同一历史曲线而不说明 |
| 新闻 | Nasdaq | 未接入的 FMP 新闻 |
| 个股期权墙 | Alpaca indicative，近月有限档 | Cboe 全市场 P/C |
| 总览期权概览 | Cboe 日终（一家交易所，非 OCC） | 个股墙 |
| 筹码 / 大单方向 | Alpaca OHLCV + SIP 逐笔估算 | 官方机构成交、富途主力 |

其它边界：

- 宏观未确认日期标「日期待确认」。FOMC 结果需公布后更新 surprise（cut / hold / hike）。
- 行业成长期 = 同主题自选同比，不是行业官方统计。
- 支撑压力来自筹码估算 + 均线，不是订单簿。
- 评分、规则偏向、模型偏向都是启发式，不是交易信号。

## 11. 明确不做

- 下单、持仓同步、账户盈亏、风控。
- 盘中真实盘口、Level 2、官方筹码、主力/散户识别。
- 用空着的 Forward PE、目标价或过短快照宣布「便宜/贵」。
- 把标题情绪分当成盘面情绪或独立决策模块。
- 把 Cboe 全市场期权与个股墙、把 IEX 与 SIP 混成同一数字。
- 为「看起来完整」而编造新闻影响、行业增速或次日预测。

## 12. 验收：怎样算满足三条需求

### 基本面

- 个股财报页能在一屏内看到一年涨跌、近四季超预期次数、营收同比/是否放缓、相对自身估值。
- 缺预期或缺增长数据时，结论显示样本不足，不把空值算进超预期次数。

### 隔日盘面

- 总览简报表不进个股也能看到：量比、5 日方向、MA5/20/50/200 位置、守住或跌破、一句健康度。
- 个股图均线与日线技术面是同一套 MA5/20/50/200。
- 打开个股图表，能换周期、看到 KDJ、看到 POC/支撑压力；筹码与资金页有代理声明。

### 复盘迭代

- `/review` 能为每个交易日留下解释材料、明日看法，并在次日出现对照结果。
- 用户确认过的判断不被日终任务覆盖。
- 能看到已确认命中率；休市日不产生假复盘。

## 13. 实现优先级

若与现状有差距，按这个顺序补齐（研究闭环优先于锦上添花）：

1. **P0 隔日盘面简报**：总览/复盘展示量比、5 日、支撑压力、MA5/20/50/200、健康度；个股图均线与之一致。
2. **P0 复盘挂上消息与板块**：日终卡附当日新闻、主题、宏观方向，标明非因果。
3. **P1 判断日志与对照**：用户字段 + 次日自动对照 + 命中率。
4. **P1 一年基本面结论**：用已有季度序列算同比与超预期次数；同主题对比，不编行业数据。
5. **P2 估值诚实化**：自身一年分位 + 明确缺失项。
6. **P2 富途模块代理**：筹码分布、分层大单、KDJ、期权墙——在诚实边界内保持可用。
